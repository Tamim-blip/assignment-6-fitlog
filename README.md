# FITLOG

**FITLOG** is a modern workout management web application designed to help users discover workouts, build personalized workout plans, and save exercises for later. It provides a clean, responsive interface for organizing daily training while keeping important workout information easily accessible.

Built with modern web technologies, FITLOG focuses on a simple user experience, responsive design, and reusable component architecture.

## ✨ Features

* 🏋️ **Workout Library** — Browse a collection of workouts with detailed information about each exercise.
* 📋 **Personal Workout Plan** — Add workouts to your personal plan and organize your daily training.
* 🔖 **Save Workouts** — Save favorite workouts for quick access later.
* 🔄 **Plan & Saved Tabs** — Easily switch between your active workout plan and saved exercises.
* 📊 **Workout Sorting** — Sort workouts by:

  * Rating
  * Duration
  * Calories Burned
* 🔥 **Workout Statistics** — View useful workout information such as duration, calories burned, ratings, muscle groups, and equipment.
* 🗑️ **Workout Management** — Add and remove workouts from your plan or saved list.
* 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile devices.
* 🎨 **Modern UI** — Dark-themed interface with a clean and minimal design.
* ⚡ **Interactive Experience** — Dynamic UI updates without unnecessary page reloads.
* 🔔 **User Feedback** — Toast notifications provide instant feedback when performing actions.
* 🧩 **Reusable Components** — Built with reusable React components for cards, buttons, dashboard sections, and workout management.
* 📦 **Context-Based State Management** — Uses React Context to manage workout plans and saved workouts across the application.
* 🚫 **Custom Empty States** — Helpful empty-state screens when no workouts have been added.
* ⏳ **Loading & Error Handling** — Includes dedicated loading and not-found experiences for a smoother user experience.

## 🎯 Core Functionality

### My Plan

The **My Plan** dashboard allows users to manage their selected workouts in one place. Users can switch between their current plan and saved workouts and sort exercises according to their preferred criteria.

### Workout Cards

Each workout card provides important information such as:

* Workout name
* Exercise image
* Muscle groups
* Equipment
* Duration
* Calories burned
* Rating

### Sorting

Users can dynamically sort their workouts based on:

```text
⭐ Rating
⏱️ Duration
🔥 Calories Burned
```

### Responsive Design

FITLOG is designed with a responsive-first approach, providing a consistent experience across:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet

## 🛠️ Tech Stack

## 🚀 Project Goal

The goal of FITLOG is to create a practical and intuitive workout management platform where users can discover exercises, organize their training plans, and keep track of their preferred workouts through a modern and responsive interface.
